Privacy Policy

Aretē OpenMind for iPhone · Effective November 21, 2026

The short version

OpenMind collects no data about you. There is no account, no sign-in, no tracking, no analytics, no advertising and no crash-reporting service. The app doesn't send anything you type, or anything about you, to us or to any AI provider.

Who we are

Aretē OpenMind is made by its developer, the seller named on its App Store page. To contact us, open a support request (see Contact below).

What the app does on the network

The app downloads one public data file over HTTPS from lemarclawclawbot-oss.github.io. That file is the same for everyone. The request contains nothing about you beyond what any web request carries (your IP address and the app's user agent). The file is hosted on GitHub Pages, and GitHub may log visitor IP addresses for security purposes, as described in the GitHub General Privacy Statement, which also covers how long GitHub keeps them. We don't receive these logs, we don't use them to identify you, and we have no analytics.

What stays on your iPhone

  • A copy of the latest public data file and when it was downloaded, so the app works offline. It isn't included in your iCloud or device backups.
  • Your appearance choice (light, dark or automatic) and whether you've seen the welcome screens.

Deleting the app deletes all of this.

Children

The app has no accounts and collects no data, from anyone of any age.

Links to other websites

The "About the data" screen can link to public web pages (for example a provider's price page). Those sites have their own privacy policies.

Changes

If a future version adds anything that sends data off your phone (for example, optional sign-in or asking AI models a question), we'll update this policy before that version is released and ask for your permission in the app first.

Contact

Open a support request on GitHub. Requests are public and need a free GitHub account, so please don't include personal information.
