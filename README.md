# arete-apps (public)
Static GitHub Pages site: privacy and support pages for Aretē iOS apps, plus the OpenMind public data feed.
Live at https://lemarclawclawbot-oss.github.io/arete-apps/

**Rules:** only public pages and the OpenMind feed go here. No code, no keys, no personal data.
Each app owns only its own folder (`praxis/`, `nexus/`, `omniprop/`, `openmind/`). `git pull --rebase` before every push. Never force-push.
